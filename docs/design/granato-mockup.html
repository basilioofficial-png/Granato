granato · UI-концепция

Пять ключевых экранов, их состояния и тёмная тема. Экраны интерактивные: таймер идёт, плитки переключают активность, вкладки и разделы кликаются. Ссылки между экранами прокручивают страницу к нужному экрану.

Пять ключевых экранов

04 · Трекер — идёт запись

Фокус — текущая активность и большой таймер. Сценарии A/B: «Сменить» → выбор активности; плитки «Недавние» переключают в одно касание — прошлая запись закрывается сама, внизу тост с «Отменить».

05 · Выбор активности

Тап по строке — сразу старт этого уровня (сценарий D: «Отдых» без подкатегорий). Кнопка › — вглубь (сценарий C: Работа › Совещания › Планёрка). Поиск работает.

07 · История дня

Лента по времени и полоса «зёрен». Неизвестные интервалы заштрихованы и заполняются в одно касание. Запись длиннее 3 ч подсвечена подсказкой «Разделить» (сценарий E).

09 · Аналитика

День / Неделя / Эксперимент. Одна полоса распределения, вывод одной фразой, рейтинг категорий с изменением, доля неизвестного по дням (сценарий F).

11 · Категории

Открывается из Профиля и из выбора активности. Дерево до 3 уровней, разворот по тапу. Категория без вложений — нормальный укрупнённый учёт.

Состояния, сценарии C и E, тёмная тема

Трекер — пустое состояние

Первый запуск. Одна главная кнопка и быстрый старт по корневым категориям — первая запись в одно касание.

Выбор — Работа › Совещания

Второй уровень. Первая строка — «Только Совещания» для укрупнённого учёта.

История — разделить запись

Сценарий E. Шкала с точками разреза, ниже фрагменты: у каждого редактируются время и активность.

Аналитика — день

Режим «День»: вместо столбцов по дням — полоса «зёрен» сегодняшнего дня.

Трекер — тёмная тема

Тёплые тёмные нейтрали, акцент — тот же гранатовый. В шапке только знак логотипа.
